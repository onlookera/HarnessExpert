# 数据回收复盘指南

## 目标
发布上线后回收各达人内容数据，形成复盘报告，指导下一轮投放。

## 步骤
1. **回收数据**：从平台创作者后台或数据平台（蝉妈妈/新榜/飞瓜）用 Playwright MCP 抓取/录入：曝光、播放、点赞、评论、收藏、分享、涨粉、点击/进店、成交 GMV 等。
2. **计算指标**：互动率=(点赞+评论+收藏+分享)/播放；ROI=GMV/总投入；转化率、客单价等。
3. **汇总对比**：把各达人数据汇总成表格（可用 `office-docs` 技能导出 Excel），按 ROI/互动率排序，标注"超预期/达标/未达标"。
4. **输出复盘**：结论 + 洞察（什么垂类/内容类型效果最好）+ 下一轮建议（加投/优化/淘汰）。
5. **归档**：把复盘要点写回工作台对应达人备注，阶段推进至"数据回收复盘"完成。

## 指标参考
曝光量、播放量、点赞量、评论量、收藏量、分享量、互动率、涨粉量、进店/点击量、GMV、ROI、客单价、退货率、转化率。
