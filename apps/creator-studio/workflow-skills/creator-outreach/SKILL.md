# 达人邀约与洽谈指南

## 目标
围绕"达人筛选→邀约→洽谈→确认合作"流程，帮用户高效沟通。

## 步骤
1. **生成邀约话术**：根据达人信息（平台、垂类、风格）从 `lib/workflow.js` 的 TALKING_TEMPLATES 或自行撰写，定制字段：{name}/{platform}/{品牌}/{类型}/{报价}/{排期}/{佣金比例} 等。语气贴合达人风格。
2. **多渠道触达**：微信/私信/邮箱——用 `office-docs` 技能（Outlook COM）或浏览器（Playwright MCP）发送/记录；先跟用户确认再发送。
3. **洽谈要点**：报价谈判（预算 vs 达人报价）、合作形式（一口价/带货佣金/置换）、排期、内容自由度、素材提供。
4. **推进记录**：每轮沟通后更新工作台里该达人的阶段（邀约→洽谈→确认）与备注（关键结论、报价、排期），保持记录完整。
5. **确认合作后**：帮用户整理合作要点（价格、档期、交付物、结算方式），形成合作备忘。

## 提醒
- 发送类操作（微信/邮件/私信）**必须经过用户确认**，不要静默群发。
- 记录真实沟通结论，不编造。
