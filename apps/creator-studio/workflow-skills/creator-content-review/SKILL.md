# 脚本 / 内容审核指南

## 目标
按广告合规与品牌要求审核达人脚本/成片，输出明确的过审意见。

## 步骤
1. 拿到脚本/成片后，逐项对照审核清单（`lib/workflow.js` REVIEW_CHECKLIST）：
   - 产品信息准确（名称/卖点/价格）；无夸大宣传；无违禁词（最好/第一/绝对/国家级等）；
   - 广告标识合规（种草需注明"广告/合作"）；口播与画面一致；品牌露出次数达标；
   - 优惠信息/链接正确；无竞品/负面；时长合规；封面标题规范；成片画质/字幕/BGM 版权。
2. 给出结论：**通过 / 打回修改**，并列出逐条问题 + 具体修改建议（指明第几秒/第几句）。
3. 涉及违禁词的，给出替换词建议（如"最好"→"很受欢迎"）。
4. 把审核意见填回工作台对应达人的备注，阶段推进（内容对接→脚本审核→发布上线）。

## 提醒
- 合规红线（医疗、金融、功效宣称）从严；拿不准的明确提示风险让用户决定。
- 审核意见具体可执行，不空泛。
