# 达人营销工作台 · 项目记忆与踩坑记录

> 用途：供其他工作区/会话快速了解本项目，避免重复踩坑。
> 仓库：github.com/onlookera/HarnessExpert（分支 `expertworek`）· 本地：`deepseek-harness\apps\creator-studio`

## 一、项目是什么
基于 DeepSeek Harness 的桌面端，面向「达人营销 8 阶段工作流」：
**筛选 → 邀约 → 洽谈 → 确认 → 内容对接 → 脚本审核 → 发布上线 → 数据复盘**。

- 姊妹版：`apps/desktop`（通用桌面端，带动态壁纸）；`creator-studio` 是其**分发版**（去壁纸、加工作流看板 + 开箱即用引导）。
- 分发要求：**谁下载读谁的记忆**（记忆库读本机使用者自己的 Codex/Claude Code 会话）；API Key 由使用者**在界面填写**；全程零命令行。

## 二、架构速览
| 模块 | 文件 | 职责 |
|---|---|---|
| 主进程 | `main.js` | 窗口、IPC、引擎自举、工作台/记忆库/引导 |
| 引擎自举 | `lib/setup.js` + `lib/dsh-boot.js` | 找/解压内置 Node → npx 装 `@deepseek-ai/dsh` → spawn `dsh web --no-open --port` |
| 工作流数据 | `lib/workflow.js` | 8 阶段、达人库 CRUD、话术/审核/复盘模板、CSV 导出、技能安装 |
| 工作台 UI | `renderer/workflow.html/css/js` | 看板 + 模板库 + 设置 + 开箱即用引导 |
| 记忆库 | `renderer/memories.html/css/js` + `lib/memory.js` | 读本机 `~/.codex/sessions`、`~/.claude/projects` 全文检索 |
| 技能 | `workflow-skills/` | 首启用自动装到使用者 `~/.agents/skills` |
| 皮肤 | `skin/skin.css` | 覆盖 harness `--dsw-static-*` 主题 token |
| 数据 | `%APPDATA%\dsh-creator-studio\` | workflow.json（业务）、memory/（索引） |

技术栈：Electron 32.3.3 + electron-builder 26；`package.json` 的 `build` 有 win/mac 双配置。

## 三、构建 / 分发（重点）
- 本地：`npm run dist`（Windows exe）；`npm run dist:mac`（需 macOS 或 CI）。
- **Windows 机器产不出 .dmg**（electron-builder 明确报错 "Build for macOS is supported only on macOS"）→ 用 GitHub Actions 的 macOS runner。
- CI：`.github/workflows/creator-studio-build.yml`，**push `expertworek` 自动触发**（也可手动 workflow_dispatch），双 runner 出包，产物在运行页底部 **Artifacts**：
  - `creator-studio-Windows`（两个 exe）
  - `creator-studio-macOS`（.dmg + .zip，arm64 + x64）
- 开箱即用：`extraResources` 内置 `node-portable.zip`（win）/ `node-v20.18.0-darwin-{arm64,x64}.tar.gz`（mac，平台级配置，只带自己平台）；首次运行自动解压、自动 npx 装引擎、界面引导填 API Key（写入 `~/.dsh/.credentials.yaml` + `settings.yaml`）。
- mac 图标用 512px PNG（自动转 icns）；.ico 仅 Windows。

## 四、踩坑记录（务必先读）
1. **别用 PowerShell Set-Content 写 JS/JSON**：会把 UTF-8 中文写坏（乱码 + 丢引号 → 整文件语法错误，Electron 拒载、静默退）。改代码用 write/edit 工具或 node。
2. **Electron 沙箱 preload**：`MutationObserver.observe(documentElement)` 会抛 "not a Node" 中断整段 preload → 必须 try/catch；`-webkit-app-region` 用 `style.setProperty`，不能 `setAttribute`。
3. **桌面端自启引擎**：不能把 `process.execPath`（electron 二进制）当 node 跑 dsh 脚本 → 必须解析真实 `node.exe`（PATH/常见路径/内置）。
4. **冒烟测试**：`process.exit(0)` 会截断 stdout 管道（无输出）→ 结果写文件（smoke-result.json）。
5. **单实例锁**：残留旧版进程会让新实例**静默退出**（exit 0 无输出）→ 测试前先杀 DSH Desktop / electron / 达人营销工作台。
6. **npm workspaces 大坑**：在带 `workspaces` 的仓库里，npm 会把子应用当 monorepo 成员去装整套依赖；且 `vendor/*` 通配符会匹配到**符号链接/文件**（如 `vendor/CLAUDE.md`）→ ENOTDIR 报错。**根 package.json 的 workspaces 已删除**（harness 用 pnpm 读 pnpm-workspace.yaml，不受影响）。以后若再引入 npm 应用子目录，注意这点。
7. **GitHub Actions 匿名 API 限流**（60/h/IP）：轮询/日志下载会 403 → 看网页；日志下载需仓库 admin 权限。
8. **harness 整体换肤**：覆盖 `--dsw-static-*` 静态 token（alias 层自动跟随），`insertCSS(css, { cssOrigin: 'user' })` + `!important` 才稳。
9. **electron-builder 7z 压缩极慢**（部分环境 >10 分钟，别误判卡死）；配 `electronDist: node_modules/electron/dist` 跳过运行时下载。
10. **GitHub 网络**：git clone/直连 github 可能瞬断 → 用 codeload 下载 tarball + curl 重试；npm 源可用 npmmirror。

## 五、常用命令
```powershell
cd deepseek-harness\apps\creator-studio
npm start          # 开发（launch.cjs 会清掉 WorkBuddy 注入的破坏性环境变量）
npm run smoke      # 无窗口冒烟，结果看 smoke-result.json
npm run dist       # Windows 打包
npm run dist:mac   # mac 打包（需 Mac 或 CI）
# 推 CI 出包：
git add -A && git commit -m "..." && git push origin expertworek
```

## 六、给其他工作区的提示
- 需要改这个项目时：先读本文件 + `docs\达人营销工作流使用文档.md`（面向使用者）+ `README.md`。
- 修改后记得推 `expertworek` 触发 CI 出包；产物在 Actions 页下载。
- 本机数据（API Key、达人库）都在 `%APPDATA%\dsh-creator-studio\`，与代码无关，换工作区不丢。
