# 达人营销工作台 — 使用文档

> 面向「达人营销工作流」的一体化桌面工具：
> **达人筛选 → 达人邀约 → 洽谈合作 → 确认合作 → 内容对接 → 脚本内容审核 → 内容发布上线 → 数据回收复盘**
> 内置 DeepSeek Harness 引擎（AI 助手）、8 阶段流程看板、达人库、话术/审核/复盘模板，以及平台自动化助手。

---

## 一、安装 / 下载

在 `dist\` 目录选择其一：

- **达人营销工作台-Setup-1.0.0.exe** — 安装版（推荐：有桌面/开始菜单快捷方式）
- **达人营销工作台-1.0.0-portable.exe** — 便携版（双击即用，免安装）

**环境要求**：Windows 10/11，并已安装 [Node.js ≥ 18](https://nodejs.org)（首次启动会自动用 npx 安装 DeepSeek Harness 引擎；有网即可）。

**首次启动**：双击 exe → 会先弹出「达人营销工作台」窗口（流程看板），同时自动拉起 harness 主窗口。第一次会下载引擎，请稍等。

---

## 二、首次使用：填写你自己的 API Key

本应用**不内置任何密钥**，每个人填自己的：

1. 在主窗口（harness 界面）点「设置」→「模型 / API」；
2. 填入你的 API Key（DeepSeek / OpenAI 等，与 dsh 兼容），保存；
3. 或设置环境变量 `DEEPSEEK_API_KEY` 后重启应用；
4. 回到「达人营销工作台」→「设置」标签，可点「🛠 安装工作流技能」把 4 个业务技能装到本机。

> 你的 Key 只存在你自己机器上（`~/.dsh/.credentials.yaml`），不会上传。

---

## 三、工作流怎么用（8 阶段）

「流程看板」按 8 个阶段竖排展示，每列是当前阶段的达人卡片：

| 阶段 | 做什么 | 建议动作 |
|---|---|---|
| 1. 达人筛选 | 按平台/粉丝/垂类找候选 | 用自动化助手筛人 → 「＋新增达人」录入 |
| 2. 达人邀约 | 发合作邀约 | 「模板库」复制邀约话术，私信/邮件发出 |
| 3. 洽谈合作 | 聊报价/形式/排期 | 沟通后把结论写进备注 |
| 4. 确认合作 | 定档 | 整理合作备忘（价格/档期/交付物） |
| 5. 内容对接 | 给产品/卖点/脚本素材 | 附件与要点记录到备注 |
| 6. 脚本内容审核 | 审脚本与成片 | 用「审核清单」逐项过，意见写备注 |
| 7. 内容发布上线 | 按排期发布 | 记录发布链接/时间 |
| 8. 数据回收复盘 | 回收数据算 ROI | 用「复盘指标」汇总，结论归档 |

**卡片操作**：
- **← / →**：退回 / 推进到上一、下一阶段
- **✎**：编辑达人信息（平台、粉丝、报价、联系方式、备注…）
- **✕**：删除
- 顶部**搜索框 / 平台筛选**：快速过滤；**⇩ 导出 CSV**：把达人库导出成表格

**达人库**：点「＋ 新增达人」录入（名称、平台、账号、垂类、粉丝量、联系方式、报价、阶段、备注）。数据实时保存到本机 `%APPDATA%\dsh-creator-studio\workflow.json`。

## 四、平台自动化（连软件干活）

主窗口 = harness（AI 助手），可以自动操作各种软件。在「设置」标签复制 MCP 配置，追加到
`%USERPROFILE%\.dsh\profiles\web\cordis.patch.yml`，重启应用后即可让 AI：

- **浏览器自动化**（Playwright）：打开小红书/抖音/数据平台（蝉妈妈、新榜、飞瓜）按条件**筛选达人**、**抓取内容数据**、**监测发布**；
- **Office 文档**：用 Excel 汇总达人/复盘报表、生成合同/备忘（Word）、Outlook 发邮件；
- **数据库**：把达人库/数据落库留档、按条件查询生成报表。

然后直接在 harness 里说人话，例如：
- “打开小红书搜索美妆达人，按粉丝 5w~20w 筛出 10 位，列成表格”
- “给阿鱼酱写一条合作邀约，报价 5000，档期下周三”
- “审一下这份脚本，按审核清单逐项给意见”
- “把这三条内容的播放、点赞、评论汇总成 Excel，算互动率和 ROI”

> 工作流专属技能（`creator-screening / creator-outreach / creator-content-review / creator-data-review`）
> 装好后，harness 会自动调用它们完成筛选/邀约/审核/复盘的标准流程。

## 五、隐私与数据（重要）

- **谁下载，读谁的记忆**：内置「记忆库」读取的是【本机使用者自己】的 Codex（`~/.codex/sessions`）与
  Claude Code（`~/.claude/projects`）会话，**不包含任何作者/他人的数据**；另一台电脑上运行会自动读到那台电脑的数据。
- 业务数据（达人库/流程/模板）只存本机：`%APPDATA%\dsh-creator-studio\`；
- 无联网上报；仅你主动填写的 API Key 用于模型调用；
- 导出文件由你自己掌握。

## 六、macOS 支持

**可以跑，但需要先在 Mac 上打一次包**（Windows 机器产不出 .dmg）：

1. 在 Mac 上安装 Node.js ≥ 18；
2. 把应用源码目录（`deepseek-harness/apps/creator-studio`）拷到 Mac；
3. 在目录里执行：
   ```bash
   npm install          # 安装依赖（Electron 等）
   npm run dist:mac     # 产出 .dmg（Apple Silicon 与 Intel 双架构）
   ```
4. 打开生成的 `dist/达人营销工作台-1.0.0-*.dmg` 安装即可。

**Mac 上的差异说明**：
- 引擎查找、数据目录、标题栏已做跨平台处理：业务数据存 `~/Library/Application Support/dsh-creator-studio/`；标题栏用 macOS 原生（红绿灯按钮）；
- 首次启动同样自动用 `npx` 安装 DeepSeek Harness 引擎（需 Node + 网络）；
- 记忆库同样读取 Mac 上**使用者自己**的 `~/.codex/sessions` 与 `~/.claude/projects`；
- 未签名应用首次打开：右键 → 打开（或 `xattr -dr com.apple.quarantine /Applications/达人营销工作台.app`）；正式分发建议做签名/公证；
- Windows 专属的 Office COM（office-docs 技能）在 Mac 上不可用，Excel/Word 会自动改用 AppleScript 或 python-docx/openpyxl。

## 七、常见问题

| 问题 | 处理 |
|---|---|
| 启动提示找不到 Node | 安装 Node.js ≥ 18 后重开；或先手动跑一次 `npx -y @deepseek-ai/dsh web` |
| 主窗口黑屏/空白 | 关闭 3080 端口占用进程后重启；或菜单「视图 → 重新加载页面」 |
| AI 说没有浏览器/MCP 工具 | 按“四、平台自动化”配置 MCP 并重启应用 |
| 记忆库为空 | 你本机还没有 Codex/Claude Code 会话；先让它们产生历史，再点「⟳ 重新扫描」 |
| 数据想换机器 | 把 `%APPDATA%\dsh-creator-studio\workflow.json` 拷过去即可 |
