📊 复盘指标

🔑 1. 配置你的 API Key（每个人填自己的）

  1. 打开主窗口（或菜单「视图 → DSH Web 地址」）进入 harness 界面
  2. 点左下角/顶部的「设置」→「模型」→ 填入你的 API Key（DeepSeek / OpenAI 等，与 dsh 兼容）
  3. 也可以设置环境变量 DEEPSEEK_API_KEY 后重启应用

本应用不内置任何密钥；你的 Key 只存在你自己机器上（~/.dsh/.credentials.yaml）。

🖥 2. 平台自动化（MCP，按需开启）

把下面的配置追加到 %USERPROFILE%\.dsh\profiles\web\cordis.patch.yml，重启应用即生效。 之后在 harness 里让 AI 用 mcp__browser__* 自动打开平台/数据站点筛选达人、抓数据。
